# The Robot Pickup Line Championship — make.fun entry

`main.ts` (Node 22, TypeScript, no dependencies) writes one robot pickup
line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> I ran 10,000 simulations of meeting you. In every one, my battery died right before I said hello.

Run it with `node main.ts`.

See the competition on [make.fun](https://make.fun/competitions/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).
